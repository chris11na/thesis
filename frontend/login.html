Регистрация: домен почты должен совпадать с организацией, которую администратор добавил в систему (например, для name@example.com в базе должна быть компания с доменом example.com).

Демо-вход: admin@example.com / admin123 или user@example.com / user123.

OAuth: кнопки появляются, если в backend заданы GOOGLE_CLIENT_* / MICROSOFT_CLIENT_* в .env. Домен почты Google/Microsoft должен совпадать с организацией в базе (как при регистрации). Redirect URI в консоли провайдера: http://127.0.0.1:8000/auth/google/callback (и аналогично для Microsoft), тот же хост/порт, с которого открыт API.
