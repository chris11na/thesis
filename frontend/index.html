Конфигуратор

Конфигуратор: выберите продукты и создайте конфигурацию. Вход — login.html.

Админка: организации, пользователи, каталог оборудования и поля правил на продукте (опции, лимиты). Конфигурации собирают пользователи с ролью User.

    Configuration
    Слева отметьте оборудование, уточните опции в панели у позиции; при необходимости задайте цель AP и подберите пакеты. Затем создайте конфигурацию — проверка ограничений на стороне сервера. Тело запроса: структура lines (см. подсказку ниже).
    Сессия debug
    Токены в localStorage. Запросы идут с Authorization: Bearer …. Выход — кнопка Выйти в шапке.
    User ID debug
    Упрощённо для прототипа; в запросе обычно подставляется id из токена.
